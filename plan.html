自動化審計軌跡 (Audit Trail)

做法：完整保留 API 請求與回傳的原始 JSON 紀錄，包含時間戳、排放因子版本、計算邏輯。

效益：證明數據從採集到計算完全自動化，無人工干預風險（Anti-tampering）。

audit_trail.jsonl 每行範例
waybill TW-2024-00001
ef_version DEFRA 2023 v1.4
co2_kg 505.05
api_ts 2024-05-21T06:01:58Z（路線 API 呼叫時間）
pipeline_ts 2026-04-29T01:56:53Z（Pipeline 執行時間戳）
routeSource ROUTES_API_v2（資料來源標記）
ISAE 3410

pipeline_run_ts 證明數字由自動化產生、非事後手改；ef_version 讓稽核員可追溯使用的排放因子版本。

互動式查核控制台 (Audit Control Tower)

做法：稽核員選中任一筆碳排紀錄，右側 Google Maps 視窗即時渲染出該趟行程的實際軌跡。

效益：滿足稽核員對視覺證據的需求，同時大幅提升查驗效率與專業感。

現況（PoC）：已以自建 HTML + Node.js 實現，搭配 Google Routes API 可渲染 1,000–2,000 點的真實路網軌跡（非估算弧線）。

長期目標：遷移至 Looker Studio，建立動態儀表板。

若稽核員堅持要求截圖，可從以下三點專業立場進行溝通：

完整性 (Completeness) 系統化存儲 100% 的路徑數據（Polyline），比人工抽樣截圖更完整，無遺漏風險。
真實性 (Data Integrity) 資料庫直連顯示，排除了人工編輯或修圖偽造的可能性（Anti-tampering）。
標準化 (Standardization) 符合國際數位審計趨勢，利用「數據標記」而非「影像檔」作為第三方查驗的佐證資料。

💡 核心論點：截圖是一次性的視覺快照，Polyline 是永久可查驗的數位軌跡——兩者的審計強度不在同一量級。

Google Routes API 啟用步驟

1 · 啟用 API
2 · 建立 Server Key
3 · 保留 Maps Key
4 · 設定 .env
5 · 安裝依賴

步驟 1 · 啟用 Routes API

前往 Google Cloud Console → APIs & Services → Library

搜尋 Routes API（注意：這是獨立於舊版 Directions API 的新服務 routes.googleapis.com）

點擊 啟用（Enable）

注意

啟用後 Google 需要 1–3 分鐘傳播設定。若立即呼叫 API 收到 403 SERVICE_DISABLED，稍等片刻再試。

步驟 2 · 建立 Server-side 專用 API Key

前往 Credentials → + CREATE CREDENTIALS → API key

Application restrictions 選 None（Python 呼叫無 HTTP Referer，設 referrer 限制會導致 403）

API restrictions 選 Restrict key → 勾選 Routes API（限縮用途，降低風險）

儲存後複製，填入 .env 的 GOOGLE_ROUTES_API_KEY

步驟 3 · 保留原有 Maps Key

原有的 GOOGLE_MAPS_API_KEY 繼續保留，供瀏覽器端 Control Tower 地圖渲染使用

建議維持 HTTP referrer 限制（只允許 localhost 或指定網域），保護配額

GOOGLE_MAPS_API_KEY

呼叫端：瀏覽器

有 Referer header → 可設 referrer 限制

觸發時機：每次點擊 Control Tower 運單

GOOGLE_ROUTES_API_KEY

呼叫端：Python 伺服器

無 Referer header → 不可設 referrer 限制

觸發時機：僅 pipeline 執行期間

步驟 4 · 設定 .env

# 瀏覽器端地圖渲染（Maps JavaScript API）
GOOGLE_MAPS_API_KEY=AIzaSy...你的金鑰...

# 伺服器端路線計算（Routes API v2）
GOOGLE_ROUTES_API_KEY=AIzaSy...另一把金鑰...

# 路線計算供應商切換
ROUTE_PROVIDER=routes

步驟 5 · 安裝 Python 依賴並執行

# 安裝依賴
pip3 install openpyxl requests

# 執行 Pipeline（Step 2 → 3 → 4）
python3 data/run_pipeline.py

# 啟動 Control Tower
node --env-file=.env server.js
