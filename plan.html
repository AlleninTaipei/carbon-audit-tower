# [[lat, lon], ...] → WKT LINESTRING(lon lat, ...)
def coords_to_wkt(coords: list) -> str | None:
    if not coords or len(coords) < 2:
        return None
    points = ", ".join(f"{lon} {lat}" for lat, lon in coords)
    return f"LINESTRING({points})"

Google Routes API 啟用步驟

1 前往 Google Cloud Console → APIs & Services → Library，搜尋 Routes API → 啟用
2 建立 server-side 專用 API Key（GOOGLE_ROUTES_API_KEY）：Application restrictions: None；API restrictions: Routes API
3 保留原有 GOOGLE_MAPS_API_KEY 給瀏覽器端地圖渲染（Maps JavaScript API），維持 HTTP referrer 限制
4 在 .env 加入 GOOGLE_ROUTES_API_KEY=... 並將 ROUTE_PROVIDER 改為 routes
5 安裝 Python 依賴：pip3 install requests，執行 python3 data/run_pipeline.py

為什麼要兩把 API Key？

GOOGLE_MAPS_API_KEY（瀏覽器）

用途：Maps JavaScript API（Control Tower 地圖渲染）

呼叫端：瀏覽器，有 Referer header

限制設定：HTTP referrer 限制，保護配額

若用於 Python：Google 回 403 Forbidden

GOOGLE_ROUTES_API_KEY（伺服器）

用途：Routes API v2（Python 路線計算）

呼叫端：Python 伺服器，無 Referer header

限制設定：Application restrictions: None

API restrictions：僅限 Routes API（縮小攻擊面）

兩把分開才能同時滿足兩端的安全需求：瀏覽器端有 Referer header 可做 referrer 限制；Python 伺服器端無 Referer，設了 referrer 限制會導致 403。分離設計讓兩端各自套用最嚴格的可行限制。
